# Admin / coordinator guide

- **Users:** create accounts, assign a role, reset passwords (user must change it at next login), deactivate leavers (history is kept).
- **Roles:** adjust permissions per role (Super Admin only).
- **Academic:** each year create a session and mark it current; then classes, sections, subjects and teacher assignments. Teachers only see assigned section/subject.
- **Syllabus:** build or import chapters/topics/subtopics per class+subject; copy a previous session's syllabus into a new one; version history shows who changed what.
- **Plans:** plan chapters at annual/monthly/weekly level; reschedule with a reason; delayed chapters feed dashboards and reminders.
- **Completions:** approve, reject or reopen teacher requests. A chapter is complete only when approved.
- **Settings:** change activity weights (total 100).
- **Reports and audit:** export Excel/PDF; Audit shows an immutable action history.
