# Teacher guide

1. Log in; change your password if asked.
2. **Daily teaching:** choose date, period, class-section, subject, chapter (topic/subtopic optional), status and a short description. *Save draft* to finish later, *Submit* to finalise. Drafts can be submitted or deleted; submitted entries are locked.
3. **Progress:** see each chapter's weighted progress. Use *Activities* to record notebook work, correction, worksheet, test and revision percentages; untick *Applicable* when an activity does not apply.
4. **Completions:** when a chapter is finished, *Request completion*; the coordinator or principal approves it.
5. **Assessments:** create worksheets/tests and enter student marks.
6. **Notifications:** reminders and announcements appear on the bell badge.
You only see your own assigned classes and subjects.
